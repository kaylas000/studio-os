# STUDIO OS v2.0.0

> **Мета-система веб-студии нового поколения, живая библиотека производственных модулей и интерактивный портал-шоукейс.**

---

## 🌟 Концепция STUDIO OS

**STUDIO OS** — это саморазвивающаяся производственная операционная система веб-студии, объединяющая:

1. **Производственный конвейер (Production Core & CLI)**:
   - Создание клиентских проектов в `/projects/` с принудительной инъекцией всех 9 систем студии.
   - Механизм **Harvesting** (`studio harvest`): автоматическое извлечение и деперсонализация удачных блоков для обогащения центральной библиотеки `/library/`.
   - Хранилище ассетов `/library/assets-vault/` с автоматической Draco-компрессией 3D-моделей, конвертацией звуков и шрифтов.

2. **Интерактивный сайт-шоукейс (Living Showcase Portal)**:
   - Построен на базе этих же систем (*Dogfooding*).
   - Каждый блок сайта — интерактивный демонстрационный стенд системы (3D WebGL заставки, скраббинг анимаций, анти-слоп сканер, 5 дизайн-архетипов, радар отступов, мобильная лаборатория, SEO-краулер, анализатор фактуры текста и Zero-Bug монитор).
   - Модальные окна скачивания ZIP-архивов систем, калькулятор заказа сайта и Drag-and-Drop загрузчик файлов с ПК прямо в папки библиотеки.

## 🏛️ 9 Монолитных Производственных Стандартов

| # | Система | Описание и Технологии |
|---|---|---|
| **01** | **Кинематографичные анимации** | Master Timeline + ScrollTrigger + Lenis 1.2s. Image Sequence скраббинг (метод Apple) + WebGL Post-processing (Bloom, Grain, Bokeh, Vignette). |
| **02** | **Анти-слоп защита (Anti-Slop)** | Фильтрация AI-клише, Delta-E детектор градиентов, хэширование DOM-структур и генератор принудительных ограничений. |
| **03** | **Тотальная мобильная адаптация** | Fluid типографика `clamp()`, переменные `safe-area-inset`, обязательный touch target ≥ 44x44px и матрица из 30+ разрешений. |
| **04** | **Контроль отступов и зазоров** | Шкала дизайн-токенов (2–192px), примитивы `<Box>` и `<Stack>`, живой Spacing Overlay радар и Stylelint AST-плагины. |
| **05** | **Голливудские 3D-заставки** | Three.js заставки (Universal Light, Marvel Particles, Cyber Glitch) с автодетектом железа и звуком Web Audio API. |
| **06** | **Сквозная SEO-инъекция** | Zod-контракты `PageSEOContract`, автогенерация Schema.org JSON-LD графа, AST-плагин для `width/height/lazy` и Playwright краулер. |
| **07** | **5 Дизайн-Архетипов** | Мгновенная трансформация сайта между *Luxury Noir, Neo-Brutalism, Cyber-Tech, Editorial Swiss, Clean Minimal* с контролем APCA. |
| **08** | **Инженерный копирайтинг** | Формулы PAS/BAB, плотность фактов (минимум 1 цифра на 25 слов), Flesch Readability > 70 и калибровка VoiceMatrix под ToV. |
| **09** | **Zero-Bug пирамида тестов** | ESLint reflow/memory AST-детекторы, Playwright матрица браузеров (Chromium, WebKit, Firefox), CDP замер утечек памяти и 60 FPS. |

## 🚀 Быстрый Старт

### 1. Запуск интерактивного сайта-витрины студии:
```bash
npm run dev
# Открывает живой портал на http://localhost:3000
```

### 2. Создание нового клиентского проекта:
```bash
npx studio new client-aurum luxury-noir
# Разворачивает проект в projects/client-aurum со всеми 9 подключенными системами
```

### 3. Сбор удачного блока в библиотеку (Harvesting):
```bash
npx studio harvest cyber-hero components
# Сохраняет очищенный компонент в /library/components/
```

### 4. Прогон полного аудита качества:
```bash
npx studio audit
```

## 📤 Заливка на GitHub

Чтобы запушить STUDIO OS в ваш репозиторий на GitHub:

```bash

git remote add origin https://github.com/ВАШ_АККАУНТ/studio-os.git

# 2. Переименуйте ветку в main
git branch -M main

# 3. Отправьте код в репозиторий
git push -u origin main
```
