# assets-vault · приёмка ассетов

Хранилище переиспользуемых тяжёлых ресурсов студии. `studio vault` читает заголовки файлов
и говорит, что не так с конкретным файлом — правила приёма ниже.

| Папка | Формат приёма | Обязательное условие |
|---|---|---|
| `3d-models/` | `.glb` | расширение `KHR_draco_mesh_compression`, иначе `npx @gltf-transform/cli draco in.glb out.glb`; бюджет 1.5 МБ на модель |
| `shaders/` | `.glsl` / `.vert` / `.frag` | uniforms с префиксом `u`, никаких `#include` вне перечисленных файлов |
| `sounds/` | `.ogg` (opus) + `.wav` мастер | ≤ 96 kbps, нормализация −14 LUFS, длительность ≤ 2 с на UI-звук |
| `fonts/` | `.woff2` | полный кириллический набор (U+0400–U+04FF), `font-display: swap`, статика по 2 начертания |
| `textures/` | `.ktx2` или `.webp` | бесшовный тайл, ≤ 1024², альфа-канал отдельно от цвета |

Файлы в `textures/.gitkeep`-папки коммитим только после проверки `studio vault`: репозиторий не должен
разрастаться бинарниками, которые не прошла приёмка.
